# الحسابات التلقائية — 3.3.22.12 (80)

الصورة الواردة من الهاتف توثّق فرع الواجهة الذي يعرض قائمة فارغة بوصفها تحميلًا منتهيًا، دون خطأ، ثم يطلب «تحديث الحسابات». كان `CloudTeamStore.load()` يرجع قائمة فارغة عند غياب جلسة جاهزة. واستُخدم مؤقت للشاشة كل 30 ثانية، ولم يكن دخول الحساب أو عودة الشبكة مرتبطين بإعادة تحميل مستقلة للحسابات. كذلك كان نشر cache يفك صور الحسابات قبل إرسال الأسماء إلى الواجهة.

أُزيل زر التحديث اليدوي ورسالة طلب إعادة التحميل. أصبح التحميل على مستوى التطبيق منذ فتحه/اكتمال تسجيل الدخول، مستقلًا عن المزامنة المالية وفتح شاشة الضبط. غياب الجلسة حالة انتظار، لا نجاح بقائمة فارغة. أحداث الجلسة والشبكة والعودة للتطبيق تستأنف الطلب مباشرة. إخفاق الشبكة يستعمل تأخيرًا متزايدًا 1، 2، 4… حتى 30 ثانية، يتوقف عند النجاح أو خروج التطبيق للخلفية؛ لا يوجد استطلاع دوري بعد النجاح ولا خدمات إيقاظ إضافية.

تُعرض الأسماء المحفوظة للمستخدم الحالي فورًا. أثناء استعادة جلسة سابقة لا تُستخدم إلا هوية الجهاز الموثقة لذلك الحساب، مع بقاء منع كشف cache لحساب آخر أو بعد تسجيل الخروج. لا توجد أسماء أو معرفات مستخدمين مثبتة في الكود ولا بيانات مالية مضافة إلى cache.

يُجلب جدول profiles بطلب مستقل، وتُنشر الأسماء قبل الصور وحالة الاتصال. التحسينات الاختيارية تعمل خارج قفل الأسماء، مع رقم جيل يمنع استجابة قديمة من تجاوز قائمة أحدث أو إعادة معلومات بعد تسجيل الخروج. تغييرات حالة الاتصال تصل عبر اشتراك user_presence القائم، وتُستدرك الحسابات بعد إعادة الاشتراك.

لا تغيير للحزمة `com.radwan.raadpharmacy` أو كلمات المرور أو مخطط الدفتر أو الديون أو التسديدات أو المشاركة اليدوية عبر واتساب. لا ترحيل لقاعدة البيانات أو تعديل RLS. الإصدار يزيد إلى 3.3.22.12 (80) ويبقى تحت فحوص توقيع الإنتاج ومقارنته بالإصدار السابق.

اختبارات الانحدار: الجلسة المتأخرة لا تنتهي بنجاح وهمي؛ حدث المصادقة أو الشبكة يقطع انتظار إعادة المحاولة؛ طلبات الفتح المتزامنة لا تنشئ طلبات متوازية؛ الإلغاء والخلفية لا يبقيان استطلاعًا؛ أسماء cache لا تستدعي فك الصور؛ استجابات التحسين القديمة لا تتجاوز جيلًا جديدًا؛ حالات الانتظار في Compose لا تعرض زر تحديث يدوي. تضاف إلى اختبارات Android/Room/Compose وFCM وlintRelease وبناء APK في فحوص GitHub.

الفحص الميداني المطلوب بعد التثبيت فوق النسخة الحالية: افتح الضبط مباشرة ثم اخرج منه وادخل عدة مرات؛ يجب أن تظهر الأسماء المحفوظة دون انتظار شبكة. افصل الشبكة وأعد فتح التطبيق، ثم أعد الاتصال؛ يجب أن يستأنف التحديث تلقائيًا. لم تتوفر هواتف فعلية لقياس زمن الفتح بالملي ثانية أو مقارنة الأداء مباشرة بتطبيقات مراسلة أخرى.
