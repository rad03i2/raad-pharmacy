# دفتر الغاز v2.7.0 — Financial Completion Feedback

يركز هذا الإصدار على لحظة إتمام الدين والتحصيل بحيث تكون أوضح وأريح أثناء الاستخدام اليومي.

## الجديد

- صوت تأكيد مالي هادئ فور نجاح العملية، وليس عند مجرد الضغط على الزر.
- نغمة مستقلة للدين، وأخرى للتحصيل، ونغمة تصاعدية ألطف عند تسديد الحساب بالكامل.
- الصوت مولّد محليًا داخل التطبيق ولا يحتاج ملفًا خارجيًا أو إنترنت.
- إشعار هاتف بعد ثانيتين من نجاح العملية.
- إشعار العمليات نفسه صامت لمنع تداخل نغمة Android الافتراضية مع صوت التأكيد المالي.
- الضغط على الإشعار يفتح حساب الزبون مباشرة.
- على Android 13+ يطلب التطبيق إذن الإشعارات عند أول عملية مالية تحتاجه.
- إذا كان خيار إخفاء المبالغ مفعلًا، لا يعرض إشعار العملية قيمة الدين أو التحصيل.
- تحسين Dialog النجاح ليؤكد بصريًا أن العملية حُفظت بنجاح.
- لا يتغير Room Schema ولا توجد Migration جديدة.
