# دفتر الغاز 2.9.1 — إصلاح إدخال المبلغ بالصوت

- إضافة تعريف خدمة RecognitionService إلى Android Manifest لإتاحة اكتشافها على Android 11 وما بعده.
- التحقق من وجود نموذج عربي محلي مثبت قبل اختيار المحرك المحلي (Android 13+). في الإصدارات الأقدم أو عند غياب النموذج، تستخدم خدمة الهاتف دون فرض العمل دون اتصال.
- تجربة العربية العامة إذا رفضت الخدمة العربية العراقية، مع عدد محاولات محدود.
- التمييز بين تجهيز الميكروفون، الاستماع الفعلي، وانتظار النتيجة النهائية.
- رسائل منفصلة لأخطاء الإذن، بدء الميكروفون، اللغة، الشبكة، الصوت وخدمة التعرف. لا يُعرض خطأ تحديد المبلغ بدل خطأ تشغيل الخدمة.
- علامة نهاية العملة توقف الالتقاط وتنتظر النتيجة النهائية؛ النتائج الجزئية لا تدخل مبلغًا في الحقل.
- إلغاء الجلسة وإزالة المؤقتات وتحرير المحرك عند الانتهاء أو مغادرة الشاشة أو إرسال التطبيق للخلفية، مع تجاهل callbacks القديمة.
- اختبارات للمحرك والتعافي من أعطال البداية، الصلاحيات، المهلات، النتائج الجزئية والنهائية، الضغط المتكرر والإلغاء.

الصوت يملأ حقل المبلغ فقط بالأرقام الإنجليزية. حفظ الدين يتطلب ضغط المستخدم على التأكيد عبر المسار الموجود. لم تُعدّل قاعدة البيانات أو قواعد التكرار أو المبالغ غير المعتادة.

التحقق الآلي لا يحاكي ميكروفون هاتف حقيقي أو دقة خدمة التعرف على لهجة المستخدم؛ يلزم التحقق على الهاتف المستهدف بعد التثبيت.
