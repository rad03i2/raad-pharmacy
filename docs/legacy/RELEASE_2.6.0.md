# دفتر الغاز v2.6.0 — Stable Release

هذه هي النسخة المستقرة الناتجة عن المراحل 1–17 بعد ترقية Release Candidate `v2.6.0-rc1` دون تغيير Schema قاعدة البيانات أو إضافة سلوك وظيفي جديد في مرحلة الاعتماد النهائية.

## حالة الإصدار

- الإصدار: **2.6.0**
- versionCode: **18**
- الحالة: **Stable — Direct Install**
- Android: **API 26+**
- التخزين: **Room 3 + SQLite**
- الواجهة: **Kotlin + Jetpack Compose + Material 3**
- عدد الشاشات: **16**
- البيانات: محلية Offline-First

## ما تم اعتماده قبل الإصدار

- قواعد محاسبية تمنع التحصيل فوق الرصيد.
- حماية تعديل/حذف الحركات من إنشاء سجل مالي غير صالح.
- Room + SQLite مع استعلامات تجميع مباشرة للتقارير.
- Coroutines + Flow بدل الحجب وإعادة تحميل قاعدة البيانات بالكامل.
- نسخ احتياطي واستعادة مع Validation ونسخة Recovery قبل الاستبدال.
- استعادة ذرّية عبر Transaction لحماية البيانات عند الفشل.
- توافق مع صيغة النسخ الاحتياطية القديمة.
- رفض النسخ ذات Schema أحدث بدل استعادتها بشكل غير آمن.
- اختبارات بيانات أكبر للزبائن والحركات.
- اختبارات Compose للعناصر الحساسة.
- `lintRelease` إلزامي.
- R8 + Resource Shrinking.
- ProfileInstaller.
- SHA-256 تلقائي للـAPK.
- Adaptive Icon + Themed Icon + Splash Screen.
- إعدادات الخصوصية وإخفاء المبالغ.
- نظام التنبيهات مع التعامل الآمن مع سحب صلاحية الإشعارات أثناء التنفيذ.

## ضمان عدم كسر البيانات

الانتقال من `v2.6.0-rc1` إلى `v2.6.0` لا يغير Room Schema؛ لذلك لا توجد Migration جديدة في مرحلة 17.

## التوقيع والتوزيع

الـAPK الناتج من CI مهيأ للتثبيت المباشر على الهاتف وموقّع حاليًا بمفتاح Debug حتى يكون قابلًا للتثبيت والاختبار بسهولة.

هذا الإصدار مناسب للتوزيع المباشر الشخصي/الداخلي. قبل النشر على Google Play يجب استخدام **Production Keystore خاص وآمن** وعدم استبداله لاحقًا، لأن هوية توقيع التطبيق يجب أن تبقى ثابتة عبر تحديثات المتجر.

## بوابة الجودة

لا يُرفع Artifact المستقر إلا بعد نجاح:

1. التحقق من أن الإصدار هو `2.6.0` وversionCode هو `18`.
2. جميع اختبارات Unit / Room / Backup / Compose.
3. `lintRelease`.
4. `assembleRelease`.
5. إنشاء SHA-256 للـAPK.

هذه المرحلة لا تضيف مزايا جديدة عمدًا؛ هدفها تثبيت نفس كود الـRC المجتاز للجودة وتحويله إلى إصدار مستقر.
