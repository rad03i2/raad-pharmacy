# دفتر الغاز v2.9.0 — Debt Safety & Voice Amount Input

يركز هذا الإصدار على منع أخطاء تسجيل الدين دون تغيير قاعدة البيانات أو مسار المحاسبة الحالي.

## الحماية من الدين المكرر

- يتعطل زر الحفظ فور بدء العملية وتظهر حالة تحميل.
- ViewModel يستخدم Mutex لمنع تنفيذ كتابتين متوازيتين من نفس المسار.
- الحماية الأساسية موجودة داخل Room/DAO Transaction.
- قبل الإدراج يتم فحص آخر دين لنفس الزبون ونفس المبلغ خلال 15 ثانية.
- إذا وُجد تطابق لا يتم إدراج صف جديد.
- تظهر نافذة تحذير، والخيار الأساسي هو **إلغاء**.
- يمكن اختيار **تسجيله على أي حال** إذا كانت عملية حقيقية ثانية، وعندها يتم تجاوز فحص التكرار بشكل صريح فقط لهذه المحاولة.

## حماية المبالغ غير المعتادة

- تستخدم آخر 9 عمليات دين حديثة خلال 180 يومًا.
- لا يظهر التحذير قبل توفر 4 عمليات حديثة على الأقل.
- القيمة المعتادة تعتمد على Median وليس Average العادي.
- يستخدم Median Absolute Deviation لتقليل تأثير القيم الشاذة.
- التحذير يحتاج فرقًا كبيرًا جدًا عن النمط المعتاد، وليس مجرد زيادة بسيطة.
- التحذير لا يمنع الحفظ؛ الخيار الأساسي هو **مراجعة المبلغ** ويمكن للمستخدم تأكيد التسجيل.

## إدخال مبلغ الدين بالصوت

- زر ميكروفون داخل نفس حقل مبلغ الدين.
- يبدأ SpeechRecognizer فقط عند الضغط على الزر.
- يفضّل Android On-device Recognition عندما يكون متاحًا.
- اللغة المطلوبة: ar-IQ.
- لا يتم حفظ التسجيل الصوتي.
- الصوت لا يسجل الدين تلقائيًا؛ وظيفته الوحيدة تعبئة نفس حقل المبلغ.
- الأرقام الناتجة تحفظ داخل الحقل بصيغة English digits.
- أمثلة مدعومة:
  - خمسة آلاف → 5000
  - سبعة آلاف وخمسمائة → 7500
  - عشرين ألف → 20000
  - خمسة وعشرون ألف → 25000
  - 5000 / ٥٠٠٠ / 5,000
- «دينار عراقي»، «دينار»، و«د.ع» تُعامل كإشارة لاكتمال العبارة عند توفر مبلغ واضح.
- إذا توقف الكلام، يتوقف الاستماع تلقائيًا.
- العبارات الملتبسة مثل «خمسة آلاف أو ستة آلاف» لا تُخمن؛ يطلب التطبيق إعادة النطق.
- اسم الزبون الموجود في الكلام لا يغير الزبون المفتوح في الشاشة.
- عند مغادرة الشاشة يتم تحرير SpeechRecognizer بالكامل.

## مسار موحد للحفظ

المبلغ المكتوب والمبلغ الصوتي يمران بنفس المسار:

Validation → Anomaly Check → Duplicate Transaction Guard → Save → Existing Success Dialog.

لا توجد دالة حفظ منفصلة للصوت.

## الخصوصية

- صلاحية الميكروفون تطلب عند أول استخدام.
- رفض الصلاحية لا يمنع الإدخال اليدوي.
- لا يحتفظ التطبيق بالتسجيل الصوتي.
- إذا كانت خدمة التعرف على الجهاز متاحة، يتم تفضيلها.
