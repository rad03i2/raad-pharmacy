# التخزين والنسخ الاحتياطي — 3.3.19.3

رقم البناء 58. يبسّط هذا التحديث واجهة النسخ الاحتياطي دون تغيير قاعدة البيانات أو تنسيق النسخ المشفرة أو مفتاح توقيع التطبيق.

## الشاشة الجديدة

- شاشة مستقلة من الضبط، بأيقونات الهاتف والبطاقة والسحابة والمفتاح.
- إجراءان أساسيان: إنشاء نسخة الآن، واستعادة نسخة.
- إعداد مجلد الهاتف وحفظ ملف مستقل في صفحة الهاتف؛ إعداد البطاقة وتفعيلها في صفحة البطاقة.
- سجل النسخ ومعاينة الاستعادة في مسار الاستعادة، بدل تكديس جميع النسخ في الصفحة الرئيسية.
- حالة Google Drive مختصرة؛ التفاصيل والسجل تظهر عند طلبها. الخدمة غير المهيأة لا تعرض أزرار طلب أو استعادة وهمية.

## إصلاحات

- لا تُعلن رسالة النجاح إلا بعد وجود نسخة كاملة متحقق منها وعدم وجود خطأ أو تغييرات معلقة في الوجهات المفعلة.
- اختيار مجلد أو تصدير ملف قبل حفظ المفتاح يفتح إرشاد حفظ المفتاح، ثم يتابع الإجراء بعد التأكيد.
- منع النقرات المتكررة أثناء العمليات واختيار الملفات؛ عدم تحديث حالة Compose من خيط الإدخال والإخراج.
- تذكر نوع وجهة اختيار المجلد أثناء إعادة إنشاء النشاط، لمنع تحول اختيار البطاقة إلى مجلد الهاتف.
- يستخدم الاستيراد مفتاح هذا التثبيت تلقائيًا، مع اختيار واضح لنسخة من هاتف آخر أو تثبيت سابق وإدخال مفتاحها. النسخ القديمة JSON باقية مدعومة.
- عدم حصر ملفات الاستيراد في أنواع MIME قليلة؛ تُفحص سلامة المحتوى قبل أي استعادة.
- رسائل عربية توضح المفتاح غير المطابق والملف غير الصالح وفقدان الإذن بدل رسائل التشفير أو تحليل JSON التقنية.
- خطأ الاتصال السحابي يعرض تعذر التحقق بدل ادعاء أن الخدمة معطلة؛ طلب النسخ الجاري يمنع الطلب المتكرر.
- لا تُلوّن رسالة نجاح طلب النسخ السحابي كلون خطأ، ولا يُعاد عرض حالة حساب سابق بعد تغير الجلسة.

## حماية البيانات والتحقق

الاستعادة تبقى بعد فحص النسخة ومعاينتها وتأكيد المستخدم، مع نسخة أمان قبل الاستبدال وتعليق المزامنة والتعديل. لا تُنشر البيانات المستعادة إلى الحساب المركزي تلقائيًا. لا يتضمن هذا التحديث تفعيل Google Drive أو أي تغيير إنتاجي في Supabase.

اختبارات Compose تغطي التنقل واختيار المصادر، قفل الإجراءات أثناء العمل، أخطاء البطاقة، تعليق المزامنة بعد الاستعادة، النص الكبير والوضع الداكن، والواجهة السحابية غير المهيأة أو المتعذرة. اختبارات نتيجة النسخ تمنع النجاح الزائف عند فشل إحدى الوجهات أو عدم اكتمال النسخة أو وجود تغييرات معلقة. صور المعاينة ضمن تقارير Android CI، مع اختبارات النسخ والاستعادة وRoom الحالية وفحص lint وتوقيع APK.
